## 2. 部署说明

- 采用 HuggingFace diffusers 官方 `AudioLDM2Pipeline` 加载 cvssp/audioldm2-large 权重（与 GitHub 仓库同一模型）。
  仓库自带 `requirements.txt` 锁定 transformers==4.30.2 并依赖 GitHub 主干 diffusers，在 Windows 上组合陈旧，
  diffusers 管线是社区维护的等效官方实现。
- 模型权重约 7.5GB（含双格式），推理 fp16 常驻显存约 3.1GB。
- 部署中遇到的一次网络中断导致权重首次下载不完整（2.0/7.5GB），已用 snapshot_download 断点续传补齐。

**踩坑记录（已解决）**：AudioLDM2 的 VAE config 是 FrozenDict 且不含采样率，vocoder 的采样率字段名为
`vocoder.config.sampling_rate`（首次部署误用 `vae.config.sample_rate` 导致 500，已修复）。

## 4. 性能数据（RTX 4080, fp16, 100 步）

| 场景 | 音频时长 | 生成耗时 | 扩散速度 | 峰值显存 |
|---|---|---|---|---|
| 管弦乐 10s（含首次加载 267s） | 10.0s | 30.3s | ~5.8 it/s | 3.15GB |

> AudioLDM2-large 比 MusicGen-medium 快一个数量级（扩散步数可调），显存占用也更低。
> 首次加载 267s 是从 HF 缓存读取 7.5GB 权重（机械盘速率限制），后续热加载快于首次。

## 6. 已知限制

1. 输出采样率 16kHz（模型架构决定），高频细节不如 MusicGen 的 32kHz。
2. 20s 为管线单次生成上限（repo 官方口径），更长音频需分段拼接。
3. 音质与提示词相关性依赖英文描述，中文提示可用但语义理解较弱。
